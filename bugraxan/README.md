# Қарақалпақстан тарийхы · Буғрахан естелиги
Кинематик анимацион ҳүжжетли фильм (16:9, 1920×1080, 25 fps, кадр 2.39:1 «синема» жолақлары менен), ~5 мин 50 с.

**Тайын видео:** `video/bugraxan_esteligi.mp4` — субтитрлер (диктор тексти) ҳәм фон музыкасы менен.

## Қурылыс
| Файл | Ўазыйпасы |
|---|---|
| `script.js` | Диктор тексти (қарақалпақ тилинде), бөлимлер ҳәм интервью орынлары |
| `film.js` | Барлық сахналар (canvas): таң, экспедиция архиви, карталар, минара, маяк, сызылма, мешит, қала жобасы, суў тасқыны, қарар, қазыў, қыс/жаз, астролябия, қатламлар |
| `film.html` | Браузерде ашса — фильм тиккелей ойнайды (`?nosubs` — субтитрсиз) |
| `soundtrack.py` | Фон музыкасы ҳәм тоўыслар: пад, дутар, ней-әўен, доира, самал, жаңбыр, импакт |
| `render.js` | Кадрлап рендер → MP4 (`node render.js out.mp4 [--nosubs]`) |
| `preview.js` | Айырым кадрларды тексериў: `node preview.js <папка> 12 40 95` |

Сахна узынлығы диктор текстиниң көлемине қарап автомат есапланады (~13 белги/сек). Текстти `script.js` те өзгертип, қайта рендер етсеңиз, ўақытлар өзи сәйкеслеседи.
