# Қарақалпақстан тарийхы · Буғрахан естелиги
Кинематик 3D ҳүжжетли фильм (16:9, 1920×1080, 25 fps, кадр 2.39:1 «синема» жолақлары менен), ~5 мин 54 с.

**Тайын видео:** `video/bugraxan_esteligi_github.mp4` (GitHub ушын қысылған нусқа; толық сапалы нусқа `node render.js` пенен қайта алынады) — латын жазыўындағы субтитрлер, алтын ҳәриплер менен анимацияланған гилт сөзлер/сәнелер ҳәм фон музыкасы менен (дикторлық даўыс кейин қосылады).

## Қурылыс (реалистлик 3D, Three.js)
Кадрлар мультфильм емес — ҳүжжетли фильм стилинде: физикалық аспан ҳәм күн, такыр топырақ, күйдирилген гербиш минара (дузланыў, эрозия, түсип қалған гербишлер), батып кеткен пахса дийўаллар, туман, сая, кинематик реңк грейдинги, bloom, плёнка дәни, 2.39:1 кадр, дрон ҳәм кран қозғалыслары.
Экранда тек тийкарғы гилт сөзлер — **қарақалпақ латын жазыўында** (мыс.: *Buǵraxan esteligi*, *S. P. Tolstov*, *XI ásir*, *60+ gektar*, *Xabar beriw ornı*, *Qala meshiti*, *Saqlanıp qalǵan*, *Qarar № 248 · 2025*, *Ilim-bilim orayı*).

| Файл | Ўазыйпасы |
|---|---|
| `script.js` | Диктор тексти (қарақалпақ тилинде), бөлимлер ҳәм интервью орынлары — сахна узынлықлары усыннан есапланады |
| `world.js` | Процедуралық текстуралар, рельеф (60 га қала дийўал излери, тепелер, қумлар), минара, харабалар |
| `sets.js` | 3D рельеф карталар (Арал, Әмиўдәрья, Мәўереннаҳр), Қараханийлер теңгеси, қарар ҳүжжети, қазыў майданы, астролябия, топырақ қатламлары, орта әсир қаласының реконструкциясы |
| `film3d.js` | Сахналар, камера, жарықландырыў, пост-процесс ҳәм латын жазыўындағы гилт сөзлер |
| `film3d.html` | Браузерде ашыў: `npx http-server` (ямаса `node -e "require('./serve')(8080)"`) → `/film3d.html` |
| `soundtrack.py` | Фон музыкасы ҳәм тоўыслар (пад, дутар, ней-әўен, доира, самал, жаңбыр, импакт) |
| `render.js` | Кадрлап рендер → MP4: `npm i && node render.js out.mp4` |
| `preview.js` | Айырым кадрлар: `node preview.js <папка> 12 40 95` |
